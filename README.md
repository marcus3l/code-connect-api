# Code Connect — comunidade de desenvolvimento

Aplicação de comunidade para desenvolvedores, com feed, artigos, autenticação e interações nas publicações. Esta etapa amplia o Code Connect com integração a uma API e recursos para comentários.

## Funcionalidades

- Feed e visualização de publicações
- Fluxos de login e cadastro com rotas protegidas
- Integração de dados pela camada de API
- Componentes para comentários e interação com posts

## Tecnologias

React, JavaScript, React Router, Axios, Vite e CSS Modules.

## Como executar

```bash
npm install
npm run dev
```

O Vite informa no terminal o endereço local da aplicação. Para criar a build de produção, execute `npm run build`.

## Contexto

Projeto educacional de front-end, organizado em componentes reutilizáveis.
